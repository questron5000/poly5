If it gets stuck
  • Nothing found. Try another USB cable or port, switch the FM‑1 off and on, and close other apps and tabs that use it.
  • It stopped while writing. Leave the FM‑1 as it is, plug the cable in again, reload this page and install again: the update carries on.
  • The FM‑1 does not start. Switch it off, hold OCT− and switch it on: the USB rescue. Then install again.
  • Back to the official firmware at any time with the FM‑1 Firmware Hub.

Both FM‑1 flash chips are supported; a unit with any other chip is refused before anything is erased. The file is checked before it is sent and every block is verified as it is written.
