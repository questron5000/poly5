Install

Put POLY5 on your FM‑1

Right from this page, for free: the synth and its 24 patches with their sequences, in one go. No download, no driver, about a minute.

Demo: no FM‑1 is touched, the steps only show what they look like.

  1. 1Your browser

    This browser can install.

    This browser can't install: it can't send firmware over USB. Open this page in Chrome or Edge on a computer.

    • ChromeCan install
    • EdgeCan install
    • FirefoxCan't install
    • SafariCan't install

  2. 2Get ready

    • Connect the FM‑1 to this computer with a USB cable that carries data, and switch it on.
    • Close anything else that uses it: Ableton or another music app, the FM‑1 Firmware Hub, other installer tabs.
    • The browser will ask to use your MIDI devices. Allow it: that is how the firmware reaches the FM‑1.
    • On a laptop? Plug in its charger, so it does not sleep halfway.
    • Coming from another firmware? Saves made with it may be lost. Patches you saved in POLY5 stay when you update POLY5.

  3. 3Test connection

  4. 4Install

    Do not unplug the FM‑1 and keep this tab open. Its screen shows the same progress.

  5. 5Done

    POLY5 is on your FM‑1. Play a few keys: each note goes to the next of the five synths.

If it gets stuck

  • Nothing found. Try another USB cable or port, switch the FM‑1 off and on, and close other apps and tabs that use it.
  • It stopped while writing. Leave the FM‑1 as it is, plug the cable in again, reload this page and install again: the update carries on.
  • The FM‑1 does not start. Switch it off, hold OCT− and switch it on: the USB rescue. Then install again.
  • Back to the official firmware at any time with the FM‑1 Firmware Hub.

Both FM‑1 flash chips are supported; a unit with any other chip is refused before anything is erased. The file is checked before it is sent and every block is verified as it is written. Installing firmware is still at your own risk.
